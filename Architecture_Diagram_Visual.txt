SYSTEM FLOW SUMMARY:
1. The User writes in the TipTap Editor, which syncs locally to IndexedDB via Yjs.
2. The user highlights text and asks the AI Studio a question.
3. The AI Panel sends the question + the live editor text to the /api/groq server.
4. The server queries the Groq LPU LLM.
5. If the AI decides to modify the workspace, it returns a JSON MCP Command.
6. The MCP Command Interceptor parses the JSON and directly updates the Editor!
